# Manufacturing DI Dashboard

Built with SQL, CTEs, Window Functions, Apache Superset, Docker, Git

Features: Visual Storytelling, Product Obsessed Dashboard for Real-time Monitoring

This project shows real-time factory defect monitoring with data storytelling.
Ideal for Product Analyst / Data Analyst interviews.

## Tech Stack
- SQL (CTE, RANK, Window Functions)
- Git/GitHub
- Apache Superset (Dashboard)
- Docker
